# sims/ — リプレイ用の版別シム凍結スナップショット

`v<REPLAY_V>/` に、その版の `sim.js` / `parts.js` / `fields.js` を**そのままコピー**して凍結する
(3ファイルは相対import で閉じているので、コピーだけで自己完結する)。

- リプレイ再生(`?r=`)は**常にここのスナップショットを動的importして使う**(live は新規戦闘専用)。
  これにより live のシムが変わっても過去の共有URLは当時のまま再生される。
- シムの挙動を変える改修をしたら: `replay.js` の `REPLAY_V` を +1 → 新しい `v<n>/` にコピー。
  `promo/2026-07-05-kouki/_work/check-freeze.mjs` が「現行版スナップショット == live」を検証する。
- スナップショットには**一切手を加えない**(コメント追記もしない=バイト等価が検証条件)。

正本のルールは `public/kouki/replay.js` 冒頭「リプレイ互換の掟」と
`promo/2026-07-05-kouki/making.md` の「■Ver13」節。
